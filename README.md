This is the DBHQ plugin marketplace for [Claude Code](https://code.claude.com/docs/en/plugins). Add it once, then install any of our tools with a single command.

## Add the marketplace

```
/plugin marketplace add dbhq-uk/marketplace
```

## Install a plugin

```
/plugin install outlook@dbhq
/plugin install trello@dbhq
```

## What's here

| Plugin | Description |
|--------|-------------|
| 📬 **[outlook](https://github.com/dbhq-uk/outlook)** | Microsoft 365 email and calendar via the Graph API - inbox, reply-all-safe replies, attachments up to 150 MB, calendar and availability |
| 📋 **[trello](https://github.com/dbhq-uk/trello)** | A pack of Trello skills - board/list/card management, shopping-list aisle sort, board status digest, and cross-board due radar |

More tools land here as we build them. Each plugin lives in its own repository under [github.com/dbhq-uk](https://github.com/dbhq-uk) and is free to use under the MIT licence.
